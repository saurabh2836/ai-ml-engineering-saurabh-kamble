## 📊 Results Highlights

- **16-bit (FP16/BF16)**: 6.4 GB – Best quality
- **8-bit (INT8)**: 3.2 GB – Excellent balance
- **4-bit (NF4)**: 2.2 GB – Massive size reduction with acceptable quality

**66% reduction in model size** while maintaining strong performance.
